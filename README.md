# 🚗 Car Service App

A modern **Flutter-based Car Service Booking Application** that allows users to book vehicle services, calculate service charges, and manage appointments with an intuitive and responsive user interface.

---

## 📱 Features

- 🔧 Book car service appointments
- 📅 Select preferred date and time
- 💰 Automatic service charge calculation
- ✅ Booking confirmation screen
- 🎨 Clean and modern Flutter UI
- 📱 Responsive design for Android & iOS
- ⚡ Fast and smooth user experience

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

---

### Installation

Clone the repository

```bash
git clone https://github.com/RiyaMahto08/Car-Service-App.git
```

Go to the project directory

```bash
cd Car-Service-App
```

Install dependencies

```bash
flutter pub get
```

Run the app

```bash
flutter run
```
